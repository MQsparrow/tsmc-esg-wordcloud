# BERT / FinBERT Experiment Plan for Final Project Progress Assignment

## Purpose

This experiment strengthens the final project by adding BERT-family semantic analysis to the existing TF-IDF and rule-based ESG / SDG dashboard.

The project already analyzes TSMC sustainability report language with:

- cleaned paragraph-level chunks
- Strategic Framing / section labels
- UN SDG labels
- TF-IDF keywords
- cosine similarity heatmaps
- representative text chunks

The BERT extension asks:

> Can a BERT-family model capture ESG / SDG meaning and concreteness beyond keyword matching?

This is useful for the final presentation because it creates a clear upgrade from the mid-term project: from keyword mining to semantic and accountability-oriented text mining.

## Recommended BERT Family Member

For the Part 1 assignment, use:

`ProsusAI/finbert`

FinBERT is a BERT-family model adapted to financial and corporate language. It is a reasonable fit for TSMC ESG reports because sustainability reports use corporate disclosure language: targets, performance indicators, commitments, achievements, risks, compliance, and stakeholder communication.

For the dashboard's semantic embedding explorer, we can also use:

`sentence-transformers/all-MiniLM-L6-v2`

MiniLM is faster and better suited for sentence-level similarity maps. FinBERT is better for the assignment narrative because classmates specifically asked for a BERT-family member connected to corporate reports.

## Important Labeling Note

A true F1 score or accuracy score requires ground truth labels. The current repo does not yet contain manually verified gold labels for all 272 chunks.

For this week's assignment, we therefore use **AI-assisted weak labels**:

- SDG weak labels come from the existing rule-based `sdg_labels` column.
- Concreteness weak labels come from transparent heuristics: numbers, dates, units, completed-action verbs, and vague future-oriented language.
- The weak labels are saved to `outputs/weak_eval_labels.csv` so the evaluation is reproducible and inspectable.

Use this wording in the report:

> Because manually verified labels are still in progress, this week's experiment uses weak labels generated from our existing rule-based SDG pipeline and concreteness heuristics. The scores should be interpreted as pilot evaluation results, not final gold-standard model performance.

This is better than inventing scores because every number is generated by code and can be reproduced.

## Experiment Track A: FinBERT Evaluation for Part 1

Script:

`src/finbert_weak_label_evaluation.py`

This track produces the metrics classmates asked for:

- FinBERT F1 score for each of the 9 SDGs
- TF-IDF baseline F1 score for each of the 9 SDGs
- overall concreteness detection accuracy
- coverage vs concreteness gap by SDG

Technical design:

- TF-IDF baseline: TF-IDF vectorizer + logistic regression classifier
- FinBERT classifier: FinBERT embeddings + logistic regression classifier
- SDG task: multi-label classification over 9 SDGs
- Concreteness task: binary classification, concrete vs vague
- Split: train/test split, default 70/30

This is not full FinBERT fine-tuning. It is a lightweight embedding-classifier experiment, which is safer for a course project and does not require GPU.

## Experiment Track B: MiniLM Semantic Similarity

Script:

`src/bert_experiments.py`

Sentence-BERT / MiniLM converts each ESG report chunk into a semantic vector. Those vectors are used for:

- semantic similarity between SDGs
- semantic similarity between ESG sections
- 2D visualization of chunk-level themes
- comparison with TF-IDF similarity

Good explanation:

> TF-IDF captures exact keyword importance, FinBERT supports a corporate-language classification experiment, and MiniLM captures semantic similarity. Together they show how the final project moves beyond keyword counting.

## Difference from the Mid-Term Project

The mid-term project was mainly keyword-oriented. It emphasized word clouds, TF-IDF, and descriptive exploration.

The final project adds:

- structured ESG / SDG framing
- FinBERT / BERT-family semantic classification experiments
- semantic embeddings with MiniLM
- validation through similarity comparison
- concreteness detection for greenwashing risk
- a clearer dashboard and presentation story

Short version for slides:

> Mid-term: What words appear important?
>
> Final: Which SDG themes are emphasized, are the claims concrete, and does BERT-family semantic analysis support or challenge the TF-IDF baseline?

## Challenges So Far

- Sustainability report text is long and noisy after PDF extraction.
- SDG labels naturally overlap because ESG issues are connected.
- TF-IDF may miss semantic similarity when different words express similar meaning.
- BERT results are less transparent than keywords, so they need clear visual explanation.
- The current F1 and accuracy scores use weak labels, so future work should replace them with manually verified labels.
- The dashboard must stay presentation-ready instead of becoming too complex.

```powershell

```

```powershell

```

```powershell
python src/finbert_weak_label_evaluation.py --force-labels
```

Force recompute FinBERT embeddings:

```powershell
python src/finbert_weak_label_evaluation.py --force-embeddings
```

```powershell
python src/bert_experiments.py --sample-size 150
```
